## 2. Гауссовский процесс с нуля (Главы 14–15)
Модули: `models/kernels.py`, `models/gp.py`

- [ ] **2.1. Ковариационные функции (Ядра)**
  - Абстрактный базовый класс `Kernel`.
  - Ядро RBF (Squared Exponential / Гауссово):
    - `k(x, x') = sigma_f^2 * exp(-0.5 * ||x - x'||^2 / l^2)`
    - Метод вычисления матрицы ковариации `K(X1, X2)`.
    - Аналитические градиенты по гиперпараметрам (длина шкалы `l`, масштаб дисперсии `sigma_f`) для быстрой оптимизации.
- [ ] **2.2. GP Regression на разложении Холецкого**
  - Класс `GaussianProcessRegressor`:
    - Инициализация ядром, шумом измерений `sigma_n` и регуляризатором (nugget/jitter `1e-6`).
    - Метод `fit(X, y)`:
      - Построение матрицы `K = k(X, X) + (sigma_n^2 + jitter) * I`.
      - Факторизация Холецкого: `L = cholesky(K, lower=True)`.
      - Решение системы через `scipy.linalg.solve_triangular` для вектора весов `alpha = L^T \ (L \ y)`.
    - Метод `predict(X_star, return_std=True)`:
      - Вычисление среднего прогноза: `mu = k(X_star, X) @ alpha`.
      - Вычисление дисперсии через промежуточное решение `v = L \ k(X, X_star)`:
        - `sigma^2 = k(X_star, X_star) - v^T @ v`.
        - Численный clamp дисперсии `>= 0` для исключения микроскопических отрицательных значений из-за погрешностей с плавающей точкой.
- [ ] **2.3. Подбор гиперпараметров (Marginal Log-Likelihood)**
  - Метод `log_marginal_likelihood(hyperparams)`:
    - `log p(y|X, theta) = -0.5 * y^T * K^-1 * y - sum(log(diag(L))) - (N/2) * log(2*pi)`.
  - Оптимизация гиперпараметров ядра через `scipy.optimize.minimize` (L-BFGS-B с ограничениями на положительность параметров).

## 3. Стратегии выбора следующей точки (Глава 16: Acquisition)
Модуль: `acquisition/criteria.py`

- [ ] **3.1. Базовый интерфейс функции сбора**
  - Класс / функции с сигнатурой `acq(X_candidates, gp_model, y_best)`.
- [ ] **3.2. Pure Exploitation (Раздел 16.1)**
  - `x_next = argmin mu(x)` (поиск точки с минимальным предсказанным средним).
- [ ] **3.3. Pure Exploration (Раздел 16.2)**
  - `x_next = argmax sigma(x)` (поиск области максимальной неопределенности модели).
- [ ] **3.4. Lower Confidence Bound (LCB)**
  - `acq_LCB(x) = mu(x) - kappa * sigma(x)` (минимизация взвешенной границы).
- [ ] **3.5. Expected Improvement (EI)**
  - Ожидаемое улучшение относительно текущего лучшего значения `y_best = min(y)`.
  - Реализация через `scipy.stats.norm` (CDF и PDF стандартного нормального закона).
- [ ] **3.6. Оптимизатор функции сбора**
  - Поиск точки минимума/максимума критерия:
    - Для 1D: плотная сетка кандидатов.
    - Для N-D: случайный многостартовый поиск (Random Restart) + локальная оптимизация через L-BFGS-B.

## 4. Контур байесовской оптимизации
Модуль: `optimizer/bayesian_opt.py`

- [ ] **4.1. Класс `BayesianOptimizer`**
  - Конструктор: целевая функция `f`, границы `bounds`, суррогатная модель, стратегия DoE, функция сбора.
  - Метод `initialize(n_init)`: генерация стартовых точек и первичный замер функции.
  - Метод `step()`: один шаг байесовской итерации (дообучение ГП -> поиск `x_next` -> вычисление `f(x_next)` -> обновление истории).
  - Метод `optimize(n_iter)`: запуск цикла на заданное число шагов.
- [ ] **4.2. Логирование и статистика**
  - Хранение массивов: `X_history`, `y_history`, `best_y_history`, время каждой итерации.
