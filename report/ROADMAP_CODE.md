## 2. Гауссовский процесс с нуля (Главы 14–15)
Модуль: `models/gaussian_process.py`

- [x] **2.1. Базовое ковариационное ядро RBF (`SqExpKernel`)**
  - Квадратично-экспоненциальное ядро с параметром длины шкалы `l`.
  - Метод `__call__(x, x1)` с поддержкой любой размерности через `np.sum((x - x1)**2)`.
- [x] **2.2. Базовая модель GP-регрессии (`GaussianProcess`)**
  - Разделение физического шума наблюдений `noise_var` и численного регуляризатора `jitter` (inflation).
  - Метод `fit(X, y)`: построение `K_xx + (noise_var + jitter) * I`, обращение матрицы, предвычисление вектора весов `theta`.
  - Метод `predict(X_star)`: расчет прогноза среднего `mu` и стандартного отклонения неопределенности `std` с численной защитой `maximum(var, 0.0)`.
- [ ] **dop 2.3. Инвертирование матриц через разложение Холецкого**
  - Замена прямого обращения `np.linalg.inv` на факторизацию $K = L \cdot L^T$ и решение треугольных систем `scipy.linalg.solve_triangular`.
- [ ] **dop 2.4. Подгонка гиперпараметров ГП (Fitting GP / MLE)**
  - Раздел 15.6: вычисление краевого логарифма правдоподобия (Marginal Log-Likelihood) и его максимизация через `scipy.optimize.minimize`.
- [ ] **dop 2.5. Другие ядра (Matérn, Exponential)**
  - Раздел 15.2: ядро Матерна (Matérn 5/2, 3/2) для моделирования не идеально гладких функций.
- [ ] **dop 2.6. Градиентно-усиленный ГП (Gradient-Enhanced GP)**
  - Раздел 15.4: модификация матриц ковариации для совместного учета значений функции $y$ и наблюдений градиента $\nabla f(x)$.

## 3. Стратегии выбора следующей точки (Глава 16: Acquisition)
Модуль: `acquisition/criteria.py`

- [x] **3.1. Базовый интерфейс функции сбора**
  - Класс / функции с сигнатурой `acq(X_candidates, gp_model)`.
- [x] **3.2. Pure Exploitation (Раздел 16.1)**
  - `x_next = argmax (-mu(x))` (поиск точки с минимальным предсказанным средним).
- [x] **3.3. Pure Exploration (Раздел 16.2)**
  - `x_next = argmax sigma(x)` (поиск области максимальной неопределенности модели).
- [x] **3.4. Lower Confidence Bound (LCB, Раздел 16.3)**
  - `acq_LCB(x) = -(mu(x) - alpha * sigma(x))` (компромисс между эксплуатацией и исследованием).
- [x] **3.5. Probability of Improvement (PI, Раздел 16.4)**
  - `acq_PI(x) = Phi((y_min - mu(x)) / sigma(x))` с защитой от нулевой дисперсии.
- [ ] **3.6. Expected Improvement (EI, Раздел 16.5)**
  - Ожидаемое улучшение относительно текущего лучшего значения `y_best = min(y)`.
  - Реализация через `scipy.stats.norm` (CDF и PDF стандартного нормального закона).
- [x] **3.7. Оптимизатор функции сбора**
  - Поиск максимума критерия через дискретный пул кандидатов `propose_candidate`.
  - [ ] dop: непрерывный многостартовый поиск (Random Restart + L-BFGS-B).

## 4. Контур байесовской оптимизации
Модуль: `optimizer/bayesian_opt.py`

- [ ] **4.1. Класс `BayesianOptimizer`**
  - Конструктор: целевая функция `f`, границы `bounds`, суррогатная модель, стратегия DoE, функция сбора.
  - Метод `initialize(n_init)`: генерация стартовых точек и первичный замер функции.
  - Метод `step()`: один шаг байесовской итерации (дообучение ГП -> поиск `x_next` -> вычисление `f(x_next)` -> обновление истории).
  - Метод `optimize(n_iter)`: запуск цикла на заданное число шагов.
- [ ] **4.2. Логирование и статистика**
  - Хранение массивов: `X_history`, `y_history`, `best_y_history`, время каждой итерации.
