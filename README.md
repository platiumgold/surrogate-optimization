# Суррогатная оптимизация

Курсовая работа по дисциплине «Численные методы» МГТУ им. Н.Э. Баумана, каф. ИУ-9.  
Теоретическая база: M. J. Kochenderfer, T. A. Wheeler. Algorithms for Optimization, Главы 13–16.

## Структура каталогов

- `doe/` — Планы начального выбора.
- `models/` — Гауссовский процесс.
- `acquisition/` — Стратегии выбора следующей точки.
- `optimizer/` — Главный контур байесовской оптимизации.
- `benchmarks/` — Тестовые функции.
- `notebooks/` — Интерактивный запуск и демонстрация.
- `report/` — Материалы, графики и текст для расчетно-пояснительной записки.
